vi / Vim チートシート

モードの切り替え・移動・編集・検索置換をキー操作で引くチートシート

ざっくり言うと
  • vi はターミナルで動くテキストエディタで、多くの Linux では vi を打つと高機能版の Vim が起動する。
  • キーで移動・操作する「ノーマルモード」と文字を打つ「挿入モード」を i と Esc で行き来する。
  • 迷ったら Esc を押してノーマルモードに戻り、保存せず抜けるなら :q!、保存して抜けるなら :wq。

モードの関係

起動直後はノーマルモード。すべての操作はノーマルモードを起点に、各モードへ入って Esc で戻ってくる。

挿入モード文字を入力するi a o などで入る
ノーマルモード移動・削除・コピー・貼り付け起動直後／Esc で戻る
コマンドライン保存・終了・置換・設定: / ? で入る
ビジュアルモード（Vim）範囲を選んでから操作するv 文字単位・V 行単位・Ctrl + v 矩形

「ノーマルモード → 各モード」へはキーで入り、各モードからは Esc でノーマルモードへ戻る。コマンドラインは Enter で実行しても戻る。

操作の組み立て方

ノーマルモードの操作は「回数」＋「何をするか（オペレータ）」＋「どこまで（移動・テキストオブジェクト）」の組み合わせでできている。覚えるのは部品だけでよい。

回数3+ オペレータd 削除+ 範囲w 単語= 3dw3 単語を削除
オペレータd 削除・c 削除して挿入・y コピー（ヤンク）・> < インデント・gU gu 大文字／小文字（Vim）
範囲w 次の単語まで・$ 行末まで・0 行頭まで・G ファイル末尾まで・t) ) の手前まで
テキストオブジェクト（Vim）iw 単語・i" 引用符の中・a" 引用符ごと・i( 括弧の中・it HTML タグの中・ip 段落
同じキー 2 回行全体が対象: dd 行削除・yy 行コピー・cc 行を書き直す・>> 行をインデント

例: ci" で引用符の中を消して書き直す、dap で段落ごと消す、yiw でカーソル下の単語をコピー。

元祖の vi や、busybox の vi のような互換実装は ~/.vimrc を読まず、使える設定も少ない。

よくある誤解

vi を開いたら終了する方法がない

Esc を何回か押してノーマルモードに戻り、:q! と打って Enter で、変更を捨てて抜けられる。保存するなら :wq。

どの環境でも vi を打てば Vim と同じ機能が使える

多くのディストリビューションでは vi が Vim（機能を絞った vim-tiny のこともある）を起動するが、Docker の軽量イメージなどでは busybox の vi で、ビジュアルモードやテキストオブジェクト、画面分割などが使えない。正体は readlink -f "$(which vi)" で確かめる（busybox なら /bin/busybox を指す）。

dd はコピーされずに消えてしまう

d で消したものはレジスタに入り、p で貼り付けられる。つまり削除は「切り取り」として使える。直前のヤンクを残したいときは "0p（最後にコピーしたもの）で貼る（Vim）。

u を押しすぎて戻した変更は取り返せない

Vim なら Ctrl + r でやり直せる。元祖の vi は取り消しが 1 段だけで、もう一度 u を押すと取り消しの取り消しになる。
