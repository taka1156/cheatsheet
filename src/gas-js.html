GAS と通常 JS の互換性

Google Apps Script（V8 ランタイム）で「いつもの JS」がどこまで動くか ＋ よく使う関数の対応表 ＋ GAS 専用の処理一覧

ざっくり言うと
  • GAS は V8 で動くので、let・アロー関数・class など ECMAScript の構文はほぼそのまま書ける。
  • ブラウザや Node.js の API（fetch・setTimeout・localStorage など）は無く、GAS のサービスで置き換える。
  • 処理はすべて同期で 1 回 6 分まで。import も npm も無いので、使うなら clasp とバンドラでまとめる。

何が動いて何が動かないか

そのまま使える 使えるが挙動が違う 無い（GAS のサービスで代替）

OK言語そのもの（ECMAScript）

  • let / const、アロー関数、class
  • 分割代入、スプレッド、テンプレート文字列
  • Map / Set、Array のメソッド
  • JSON、Math、RegExp
  • encodeURIComponent など

△あるが違う

  • Promise / async：書けるが I/O は全部同期
  • Date：タイムゾーンはスクリプトの設定
  • console.log：実行ログ・Cloud Logging に出る
  • グローバル：全 .gs ファイルで 1 つの空間を共有

NGブラウザ・Node の API

  • fetch、XMLHttpRequest
  • setTimeout / setInterval
  • localStorage、process.env
  • btoa / atob、crypto、URL
  • import / require、npm

よく使う関数の対応表

左が通常の JS（ブラウザ・Node.js）、右が GAS での書き方。カテゴリのタブで切り替え、入力欄で全カテゴリを絞り込める。

状態: 同じ そのまま動く／差あり 動くが挙動が違う／代替 別の GAS の API で書く／無い 相当する API が無く自作する

GAS 専用の処理（メール・スプシ・ドライブなど）

通常の JS には対応するものが無い、Google のサービスを操作する API。初回実行時にそのサービスへの権限の承認を求められる。

やりたいこと書き方メモ
メールを送る（送信だけ）MailApp.sendEmail(to, subject, body)送信専用で、必要な権限が狭い。送るだけならこちら
HTML・CC・添付付きで送るMailApp.sendEmail(to, subject, body, { htmlBody, cc, bcc, name, replyTo, attachments })attachments は Blob の配列（file.getBlob() など）
Gmail から送るGmailApp.sendEmail(to, subject, body, options)引数は MailApp とほぼ同じ。受信箱の読み書きもできる分、権限が広い
下書きを作るGmailApp.createDraft(to, subject, body, options)送る前に人が確認したいときに
メールを検索するGmailApp.search('from:foo@example.com is:unread', 0, 50)Gmail の検索演算子がそのまま使える。スレッド（GmailThread）の配列を返す
スレッドのメッセージを読むthread.getMessages()getSubject()・getFrom()・getDate()・getPlainBody()・getAttachments()
既読にする・ラベルを付けるthread.markRead() / thread.addLabel(GmailApp.getUserLabelByName('処理済み') || GmailApp.createLabel('処理済み'))処理済みの印にすると、次回の検索で除外できる。ラベルが無いときに備えて作る処理も書く

スプレッドシートを開くSpreadsheetApp.getActiveSpreadsheet() / SpreadsheetApp.openById(id)バインドしたスクリプトなら getActive…、別のファイルは ID か openByUrl(url)

範囲を指定するsheet.getRange('A1:C10') / sheet.getRange(row, col, numRows, numCols)行・列は 1 始まり

表示どおりの文字列で読むrange.getDisplayValues()書式（桁区切り・日付の形）を適用した文字列

スプシ: 1 セルずつではなくまとめて読み書きする

// 遅い: 行ごとに API を呼ぶ
for (let r = 2; r <= last; r++) sheet.getRange(r, 3).setValue(sheet.getRange(r, 1).getValue() * 2);

// 速い: 1 回で読んで、配列で計算して、1 回で書く
const values = sheet.getRange(2, 1, last - 1, 1).getValues();
const out = values.map(([v]) => [v * 2]);
sheet.getRange(2, 3, out.length, 1).setValues(out);

未読メールをスプシに書き出して既読にする

検索はスレッド単位なので、isUnread() で未読のメッセージだけに絞る。シート「受信」は先に作っておく。

function exportUnread() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('受信');
  const threads = GmailApp.search('is:unread label:inbox', 0, 50);
  const rows = threads.flatMap(t => t.getMessages().filter(m => m.isUnread()).map(m =>
    [m.getDate(), m.getFrom(), m.getSubject(), m.getPlainBody().slice(0, 200)]));
  if (rows.length) sheet.getRange(sheet.getLastRow() + 1, 1, rows.length, 4).setValues(rows);
  threads.forEach(t => t.markRead());
}

書き換えの例

fetch → UrlFetchApp（JSON を POST）

// 通常の JS
const res = await fetch(url, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${token}` },
  body: JSON.stringify(data),
});
if (!res.ok) throw new Error(res.status);
const json = await res.json();

// GAS
const res = UrlFetchApp.fetch(url, {
  method: 'post',
  contentType: 'application/json',
  headers: { Authorization: `Bearer ${token}` },
  payload: JSON.stringify(data),
  muteHttpExceptions: true,   // 4xx・5xx でも例外にしない
});
if (res.getResponseCode() >= 400) throw new Error(res.getContentText());
const json = JSON.parse(res.getContentText());

待ち・リトライ

function fetchWithRetry(url, retries = 3) {
  for (let i = 0; i < retries; i++) {
    const res = UrlFetchApp.fetch(url, { muteHttpExceptions: true });
    if (res.getResponseCode() < 500) return res;
    Utilities.sleep(1000 * 2 ** i);   // setTimeout の代わり
  }
  throw new Error('retry over');
}

日付を日本時間で整形

const now = new Date();
Utilities.formatDate(now, 'Asia/Tokyo', 'yyyy/MM/dd HH:mm');   // 2026/11/27 09:30
Utilities.formatDate(now, 'UTC', "yyyy-MM-dd'T'HH:mm:ss'Z'");  // ISO 形式（toISOString() はミリ秒 .000Z 付き）

押さえておく制限

  1. 1 回の実行は 6 分まで長い処理は途中経過をプロパティに保存し、時間トリガーで続きから再開する。
  2. 処理はすべて同期async を付けても UrlFetchApp などは待つ間ブロックする。並列にしたいときは fetchAll。
  3. サービスごとに 1 日の割り当てがあるURL Fetch の回数などは無料アカウントと Workspace で上限が違う。最新の値は公式の割り当て表で確認する。
  4. グローバルのコードは毎回走る関数の外に書いたコードは、どの関数を実行しても全ファイル分が先に実行される。重い初期化は関数の中に入れる。

よくある誤解

V8 になったので async/await で fetch を並列にできる

async・await・Promise は構文として書けるが、fetch は無く、UrlFetchApp.fetch は同期で結果を返す。並列にしたいときは UrlFetchApp.fetchAll にリクエストの配列を渡す。

new Date() は常に UTC で動く

Date の内部値は UTC だが、getHours() などのローカル時刻はスクリプトのタイムゾーンで計算される。appsscript.json の timeZone を確認し、表示は Utilities.formatDate でタイムゾーンを明示する。

ファイルを分ければスコープも分かれる

すべての .gs ファイルは 1 つのグローバル空間を共有する。別ファイルの同名の関数・変数は衝突するので、オブジェクトや class にまとめて名前空間の代わりにする。
